Skills for Claude and other AI assistants

You can use these skills with Claude or another AI assistant. Download the folder you need and hand it to your assistant.

  • uxdm-pmis-lernbegleiter
    Practice partner for the module Multimodal, Interactive Systems (M.Sc. User Experience Design, TH Ingolstadt). Always use when questions about this module's content, its exercise sheets, or exam preparation come up.
  • uxdm-pmis-t07-conversational
    Session add-on for T07 (Voice Dialogs: Written and Generated) of the module Multimodal, Interactive Systems. Use together with the module's practice partner when working on voice and conversational interface questions.
  • uxdm-pmis-t10-accessibility-law
    Session add-on for T10 (Accessibility: Law and Checking) of the module Multimodal, Interactive Systems. Use together with the module's practice partner when working on accessibility law, standards, and automated testing.
  • uxdm-pmis-audit-trainer
    Trainer for the four-step audit method (assumptions → states → edges → provenance) of the module Multimodal, Interactive Systems. Use from session T09 on, with a UI the student brings — the skill asks the questions but never delivers findings.
  • uxdm-pmis-exam-drill
    Exam training at judgment level for the module Multimodal, Interactive Systems. Use from T10 until the written exam — poses cases only in the formats rehearsed in class, and reveals the expectation horizon only after a committed answer.
  • uxdm-pmis-milestone-check
    Pre-submission check for the exercise blocks Ü1–Ü6 of the module Multimodal, Interactive Systems. Use in the last hours before an exercise upload to verify the submission package is complete — never to build any part of it.
