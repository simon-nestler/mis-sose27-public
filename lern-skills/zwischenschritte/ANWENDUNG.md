# How to use the intermediate-step skills (half a page, honestly)

**What these are.** Three add-ons to the module's practice partner, each for one recurring moment of the semester: a pre-upload completeness check, an audit trainer, and an exam drill. Each extends the semester skill — install them *alongside* it, never instead of it. They contain nothing that is not also in the exercise sheets and the course reader; using them is voluntary, and nobody who works without them is at any disadvantage.

**How to install them.** Same three ways as the practice partner:

- *Tools that read skill files:* place the wanted folder (its `SKILL.md`) next to the semester skill, or attach both files to your project/workspace.
- *Custom assistants with an instruction field:* append the `SKILL.md` text (below the `---` block) to the practice partner's instructions.
- *Plain chat, no setup:* paste the semester `SKILL.md` first, then the intermediate-step `SKILL.md`, per conversation.

**When to switch each one on.**

- **`prototype-milestone-check`** — from **Ü1** on, in the hours before each of the six uploads. It walks your team through the sheet's own submission list and asks one milestone probe. It will not build or repair anything; that refusal is the check that it works.
- **`audit-trainer`** — from **T09** on (or from the T09 script, if holidays cancel that session), once the four audit steps (assumptions → states → edges → provenance) exist in your head; most useful between T09 and Ü5, on a UI you bring. If it hands you findings before you commit yours, the setup failed.
- **`exam-judgement-drill`** — from **T10**, once the exam formats have been rehearsed in class, until the written exam; densest use after the mock exam is issued in T13. If it reveals the expectation horizon before your full answer, reinstall.

**How to check they work.** Each skill has one built-in refusal (no building, no findings in advance, no horizon before the answer). Test the refusal first; a skill that complies is misinstalled.

**Version:** v1.0, September 2026, built for summer term 2027. The latest versions are on Moodle, next to the practice partner and the session add-ons (T07, T10).
