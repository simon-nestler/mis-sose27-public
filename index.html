  • uxdm-pmis-t07-conversationalSession add-on for T07 (Voice Dialogs: Written and Generated) of the module Multimodal, Interactive Systems. Use together with the module's practice partner when working on voice and conversational interface questions.
  • uxdm-pmis-t10-accessibility-lawSession add-on for T10 (Accessibility: Law and Checking) of the module Multimodal, Interactive Systems. Use together with the module's practice partner when working on accessibility law, standards, and automated testing.
  • uxdm-pmis-audit-trainerTrainer for the four-step audit method (assumptions → states → edges → provenance) of the module Multimodal, Interactive Systems. Use from session T09 on, with a UI the student brings — the skill asks the questions but never delivers findings.
  • uxdm-pmis-exam-drillExam training at judgment level for the module Multimodal, Interactive Systems. Use from T10 until the written exam — poses cases only in the formats rehearsed in class, and reveals the expectation horizon only after a committed answer.
  • uxdm-pmis-milestone-checkPre-submission check for the exercise blocks Ü1–Ü6 of the module Multimodal, Interactive Systems. Use in the last hours before an exercise upload to verify the submission package is complete — never to build any part of it.
